# NEON GROOVE 街舞教练课程站

从零实现的街舞工作室网站：前台展示舞种风格、教练团队、少儿成果视频与试听预约入口；
后台用**持久数据库**维护场地、教练、年龄分组、排课、候补/邀请与媒体授权。

## 运行

```bash
npm install
npm run seed          # 初始化 data/app.db 种子数据（可重复执行）
npm start             # http://localhost:3000
npm test              # 16 个验收场景测试
```

- 前台：http://localhost:3000
- 管理后台：http://localhost:3000/admin ，默认令牌 `dev-admin-token`（可用环境变量 `ADMIN_TOKEN` 覆盖）
- 数据库：`data/app.db`（sql.js/WASM SQLite，每个写事务提交后原子落盘，无需原生编译）
- 可配置项：`PORT`、`DB_FILE`、`ADMIN_TOKEN`

## 核心业务规则

### 预约与容量
- **实际容量 = min(班级设定容量, 场地容量)**；管理页明确解释口径，临时换到小场地时不踢人、但标出超额。
- 选课卡上的**剩余名额仅为提示**。确认报名时在一个事务内重新原子核对：
  班级状态、**资源版本**、教练启用、场地启用、年龄分组、同场重复占位、学员多场占场上限、容量。
- 资源版本 `version`：换场/代课/改期生效即 +1。旧卡片提交返回 `409 RESOURCE_CHANGED` 并附最新排课，
  避免用户基于过期信息抢到“已经不存在的名额”。
- 并发“争最后名额”由串行写事务保证**恰好一人确认**，绝不超卖；未勾选候补者得到 `409 CLASS_FULL`。

### 候补、自动递补与人工邀请
- 名额释放（取消确认/邀请过期/拒绝改期退出）时，按 `waitlist_rank` FIFO **自动递补**（可在设置中关闭）。
- 自动递补与**人工邀请**都把候补升级为 `invited` 占位并开始倒计时，都会检查学员多场占场上限。
- **邀请有效期**默认 24 小时（可配置）；逾期后接受返回 `410 INVITE_EXPIRED`，过期标记与顺延已先行落库。
- **同一学员多场占位**上限默认 2，统计口径 = confirmed + 未过期 invited；达上限时第 3 场只能候补，后台也无法邀请。
- 接受邀请的瞬间重新核对教练/场地/容量/上限，防止“接受时资源已变”。
- 防重复点击：提交锁 + `Idempotency-Key`（同键同体重放首结果，同键异体重体拒绝）。

### 排课变更
- **临时换场 / 教练代课**：立即生效，事务内检查新场地/新教练与既有排课的时间重叠，版本 +1，全程留痕。
- **改期**：先产生 pending 提案；学员卡片显示“待确认改期”，可接受或退出（退出即释放名额并递补）；
  后台确认时再次原子核对冲突，冲突则拒绝生效；也可撤销提案。

### 少儿成果视频授权
- 授权是**独立对象**（`granted` + 可选到期时间），未授权/过期/撤销的视频不出现在公开列表。
- 撤下不是“从列表隐藏”，而是一个带进度清单的流程，逐项处理：
  **分享入口停用 → 封面移隔离区 → 片段隔离 → 转码产物隔离/在途任务丢弃 → 原始文件标识隔离**；
  受控流与分享链接随后返回 **410 Gone**。
- **旧转码任务迟到**：完成落库前重新核对授权，已撤销/已到期则产物 `discarded`、不发布、不写输出路径。
- 授权到期由扫描任务自动走同一撤下流程。
- **已被监护人/访客下载到本地的外部副本，平台无法远程抹除**——前台页脚与管理页都明确告知，不做虚假承诺。

### 可访问性与移动端
- 移动端汉堡菜单（aria-expanded）；动效总开关持久化并默认遵循 `prefers-reduced-motion`。
- 关闭动效后所有信息完整可读，不依赖动画或 hover；提供跳到正文链接。

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/classes[/:id]` | 场次卡片（剩余量仅提示）/ 详情含预约名单 |
| POST | `/api/bookings` | 报名（body 可带 `expected_version`、`join_waitlist`；头带 `Idempotency-Key`） |
| POST | `/api/bookings/:id/cancel` | 取消（触发自动递补） |
| POST | `/api/invitations/:id/accept|decline` | 接受/放弃候补邀请 |
| GET | `/api/my-invitations?phone=` | 学员查询自己的邀请与有效期 |
| POST | `/api/schedule-changes/:id/respond` | 学员对改期提案表态 |
| GET | `/api/achievements` | 仅返回授权有效视频 |
| GET | `/api/media/videos/:id/stream` | 受控流，撤下/过期 410 |
| GET | `/api/share/:token` | 分享入口，撤下后 410 |
| * | `/api/admin/*` | 需 `X-Admin-Token`：资源 CRUD、换场/代课/改期、人工邀请、设置、视频授权/转码/撤下 |

## 验收场景（见 `test/`）

1. 两人争最后名额（并发，恰好一人确认，一人候补，绝不超卖）
2. 临时换场（冲突拒绝、小场地收缩容量、版本拦截旧卡片）
3. 教练代课（新教练冲突拒绝，停用教练不可代，成功留痕）
4. 候补自动递补 vs 人工邀请、邀请有效期与取消竞争、重复点击幂等
5. 邀请过期 410 且自动顺延；学员多场占场上限
6. 待确认改期：学员拒绝即退出递补；确认时资源被占则拒绝生效
7. 旧视频转码任务迟到：授权有效才落库，撤销/到期后迟到丢弃
8. 撤销授权：封面/片段/分享/流全部处理、410、进度清单可审计；到期扫描；持久化重启
